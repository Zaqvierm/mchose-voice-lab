# MCHOSE Voice Lab

Русский · [English](README.md) · [简体中文](README.zh.md)

Браузерный редактор уведомлений MCHOSE и исследование формата звуковых ресурсов ACT/AAC.

**[Открыть редактор](https://zaqvierm.github.io/mchose-voice-lab/)** · [Официальный обновлятор для ПК](https://cdn.mchose.com.cn/OTA/PC/prod/index.html#/select)

## Возможности

- Загрузка проверенного оригинала из каталога или выбор локального образа.
- Просмотр реальных звуковых ресурсов и прослушивание оригинала.
- Обрезка аудио, кодирование AAC-LC, упаковка ACT и сборка прошивки.
- Сохранение программы, загрузчика, карты разделов и остальных ресурсов.

Обработка выполняется в браузере. Пользовательские файлы не отправляются на сервер. Редактор не прошивает устройства. Аудиодвижок (~31 МБ) загружается при первом использовании.

## Область проверки

В каталоге 8 официальных образов для 5 моделей. Каждый пересобирается без изменений побайтно. Все 144 ACT проходят проверку AAC и точную обратную упаковку. **На устройстве подтверждён Power On для X9 с английской 1003.** Остальные профили проверены программно.

Для неизвестных образов доступен только просмотр. Лимит исходника — 25 МБ / 10 минут; итоговый звук должен помещаться в штатный раздел.

Node.js 22+: `npm ci`, `npm test`, `npm run dev`. Продакшен: `npm run build`; просмотр: `npm run preview`. Публикация — GitHub Actions / Pages. CLI-команды приведены в [English README](README.md).
