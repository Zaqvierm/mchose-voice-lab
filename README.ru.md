# MCHOSE Voice Lab

Русский · [English](README.md) · [简体中文](README.zh.md)

Независимое исследование прошивок MCHOSE и браузерный редактор звуковых уведомлений.

**Сайт:** https://zaqvierm.github.io/mchose-voice-lab/

Выберите наушники и язык заводского образа из каталога или загрузите свой файл. Сайт прочитает фактические звуковые ресурсы, даст послушать оригинал, обрезать своё аудио, проверить результат после кодирования и скачать собранную прошивку.

## Подтверждённые результаты

- ACT у X9 — оболочка над стандартным AAC-LC ADTS. Все 36 заводских файлов EN/CN, 648 кадров, декодируются и собираются обратно побайтно.
- Найдены все 8 образов гарнитур для 5 моделей из актуального официального PC-каталога. Это не утверждение, что найдены все когда-либо выпущенные наушники MCHOSE.
- Все 144 ACT из этих образов проходят структурную проверку AAC и точную обратную упаковку. Все 8 образов пересобираются без изменений побайтно.
- Воспроизведение своего Power On подтверждено пользователем на настоящих X9 с английской 1003. Остальные модели и отдельные уведомления не объявляются аппаратно проверенными.

Сборка разрешена только для явно перечисленных хешей оригиналов. Неизвестный файл можно исследовать, если распознаётся файловая система, но нельзя молча пересобрать по правилам другой модели. Список звуков читается из образа; подписи вроде «Включение» — только подсказки.

## Работа и ограничения

[Инструкция](docs/rebuild.ru.md) · [Исследование](docs/research.ru.md) · [Происхождение каталога](docs/firmware-catalog.md) · [Проверки](docs/validation.md)

Аудио и прошивка обрабатываются локально. Загрузки ваших файлов на сервер нет. Сайт не подключается к USB и не прошивает устройство. Аудиодвижок (~31 МБ) загружается при первом использовании.

Ограничения на количество слов нет. Проверяется фактический размер закодированного ресурса и ёмкость штатного раздела. Лимит исходника 25 МБ / 10 минут введён для ресурсов браузера.

Оригинальные прошивки не хранятся в исходном Git. При сборке сайта скачиваются проверенные неизменённые базы с сервера производителя: это позволяет выбирать их из каталога, несмотря на отсутствие CORS у оригинальных бинарников. В `public/catalog.json` сохранены URL и SHA256. Прошивки остаются собственностью соответствующих правообладателей; лицензия MIT нашего кода на них не распространяется.

## Разработка

Нужен Node.js 22+: `npm ci`, `npm test`, `npm run dev`. Продакшен: `npm run build`, просмотр: `npm run preview`. Публикация — GitHub Actions / Pages. Полные CLI-команды находятся в [English README](README.md).
