# 构建自定义提示音

[Русский](rebuild.ru.md) · [English](rebuild.en.md) · 简体中文

1. 在目录中选择准确的耳机型号与语言，加载原始固件；也可选择本地原厂 `.bin`。哈希必须匹配明确支持的配置。不要选择接收器镜像或已修改的文件作为基础。
2. 查看镜像内真实的声音资源并试听原音。友好事件名称只是提示，不决定文件路径。未知格式可以显示，但不会被 AAC 写入器盲目替换。
3. 加载音频，选择开始与结束时间，再生成提示音。网站会生成 16 kHz 单声道 PCM，加上短淡入淡出和峰值限制，然后编码 AAC-LC 24 kbit/s，封装 ACT，并再次解封装、解码以供试听。
4. 先试听最终效果，再构建并下载 `.bin` 和验证报告。程序、DSP、引导程序、参数和其他声音保持不变，不修改固件版本和闪存分区表。
5. 通过[官方 MCHOSE 升级工具](https://cdn.mchose.com.cn/OTA/PC/prod/index.html#/select)单独安装。选择**耳机，不是接收器**。先充电，保持稳定连接，写入时不要断开。如果工具拒绝文件或版本，停止并记录错误，不要随意提升版本号。
6. 完全关机再开机。首次测试先不要戴在耳朵上，确认音量正常且无噪声；然后检查新提示音、其他通知、麦克风和电脑音频。

已完成的硬件验证只有 X9 英文 1003 的开机声音替换。其他配置通过结构检查及原镜像的精确重建，但未在真实设备上测试。修改固件没有厂商保证，拥有原厂文件不代表一定能够紧急恢复。

如果此前安装过实验性 PCM 应用补丁，请先确认如何恢复原厂程序，同版本升级可能跳过程序写入。网站不会自动提高版本或绕过升级检查。

没有按字数或词数限制。最终 ACT 必须放得进原有声音分区，名称与路径保持原样。当前配置的声音分区均为 122880 字节，但可用空间不同。

## 能否直接在本站刷机？

官方工具使用 **WebHID**。可以在支持的 Chromium 浏览器、HTTPS 页面和用户主动选择设备的条件下实现兼容协议。但本站目前**没有直接刷机功能**：必须另行验证 HID 数据包、目标设备身份、超时、中断恢复行为与真实硬件。能正确生成镜像，并不等于已经验证了写入流程。
