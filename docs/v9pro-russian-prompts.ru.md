# Русская озвучка MCHOSE V9 Pro: эксперимент

Этот сценарий собирает русские голосовые подсказки для **MCHOSE V9 Pro с гарнитурной прошивкой 1015**. Это исследовательская сборка, не официальный языковой пакет MCHOSE. Приёмник не меняется.

## Что подтверждено

- Базой служит официальный образ гарнитуры 1015 с SHA-256 `4893aba8c1b8b6007c7bc4a6a7d5b4c449787773a4b720313e23e87eb4dc290b`.
- Для пользовательского образа с восемнадцатью заменёнными подсказками проверены контрольные суммы контейнера и разделов; разделы приложения, загрузчика и параметров остались неизменными.
- Владелец проекта сообщил, что официальный обновлятор успешно установил исправленную сборку с фразой «Устройство подключено».
- Успешный экран обновлятора подтверждает установку файла, но сам по себе не доказывает, что каждая фраза проверена на слух. Подтверждение относится только к V9 Pro 1015 и гарнитуре, не к приёмнику, Turbo, X9 или другим моделям.

## Сборка со своими записями

1. Получи официальный образ **V9 Pro headset 1015** из источника MCHOSE и проверь его SHA-256 скриптом — подменённые или другие версии он отклонит.
2. Подготовь восемнадцать MP3, по одному для каждого ID из таблицы. Используй аудио, на которое у тебя есть права. Например, его можно синтезировать или записать самостоятельно. Референсная запись голоса и аудио автора проекта в репозитории не публикуются.
3. Установи Node.js 22+, клонируй проект, выполни `npm ci` и запусти:

   ```sh
   node scripts/build-v9pro-ru-pack.mjs stock-V9Pro-1015.bin ./prompts ./V9Pro-1015-custom.bin
   ```

   В `./prompts` должны лежать `V_BATLOW.mp3`, `V_BATTLO.mp3`, …, `V_USBDIS.mp3`. Скрипт создаст образ и соседний JSON-отчёт. Он не загружает файлы и не прошивает устройство.
4. Прослушай все исходные фразы и после сборки проверь целостность отчётом. До любой записи сохрани оригинальный образ именно своей модели и версии.
5. Установка выполняется отдельно через официальный обновлятор MCHOSE. Выбирай **гарнитуру**, не приёмник. Не отключай USB и питание во время записи; если обновлятор отклоняет файл, остановись.

Прошивка может повредить устройство, а наличие сохранённого оригинала не гарантирует восстановление после сбоя. Этот сценарий не является официальной поддержкой MCHOSE.
