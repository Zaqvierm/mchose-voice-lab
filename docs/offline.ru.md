# Экспериментальная офлайн-сборка

Русский · [English](offline.en.md) · [简体中文](offline.zh.md)

Python CLI работает только с точными оригиналами V9 Pro 2 0032/1002, R9 0018 и G9 V2 0031. Проверены структура и изменения файлов, **запуск изменённых образов на этих наушниках нами не проверен**. Утилита не ищет устройства и не прошивает их. Для девяти образов AAC/ACT остаётся браузерный редактор; для новых четырёх используется этот отдельный путь.

Скачайте исходники репозитория архивом или клонируйте его. Папку `tools` нужно сохранить целиком. Требуются Python 3.10+ с LZMA и обычный FFmpeg в PATH. Для преобразования WTS на G9 дополнительно нужны Windows и официальные аудиоинструменты. Пользовательские файлы обрабатываются локально.

1. Скачайте оригинал для точной модели и версии с [сайта](https://zaqvierm.github.io/mchose-voice-lab/).
2. Прочитайте образ и список реальных ресурсов:

```sh
python tools/voice_lab.py inspect original.bin
python tools/discover.py original.bin > discovery.json
python tools/voice_lab.py extract original.bin --directory extracted-sounds
```

3. Только для G9 скачайте официальные файловые конвертеры. Команда проверяет SHA256 и не запускает их:

```sh
python tools/voice_lab.py prepare-tools --tools-dir tools/vendor-tools
```

4. Соберите экспериментальный образ с коротким фрагментом. Имя ресурса берите из `inspect`:

```sh
# V9 Pro 2 / R9: номера ресурсов; привязка к событиям не подтверждена
python tools/voice_lab.py replace original.bin --resource prompt-00 --audio voice.wav --start 0 --duration 0.4 --output custom.bin --experimental

# G9 V2: настоящее заводское имя файла
python tools/voice_lab.py replace original.bin --resource tone_zh/power_on.wts --audio voice.wav --duration 0.4 --output custom.bin --experimental
```

Рядом появятся `custom.preview.wav` и `custom.report.json`. Сначала прослушайте предпросмотр. Успешная сборка не подтверждает, что устройство примет файл. Оригинал и существующие результаты не перезаписываются. Утилита не повышает версии и не обходит проверки обновлятора. Установка выполняется отдельно по инструкции производителя для конкретной модели; веб-обновлятор MCHOSE не считается совместимым со всеми моделями автоматически.

Для SBC сохраняются размер, число кадров и заводской bitpool — 53 или 60. Короткая запись дополняется тишиной, слишком длинная отклоняется, а не обрезается молча. WTS должен помещаться в старый слот; адреса и размер образа сохраняются. Исходник — до 25 МБ; фрагмент WTS — до 30 секунд, но для штатного слота обычно нужен гораздо более короткий звук. Если FFmpeg не найден, укажите `--ffmpeg /путь/к/ffmpeg`. Аудиоинструменты G9 запускаются только после совпадения их хешей.

Для AAC/ACT на X9, G9 Pro, V9 Pro и Turbo используйте браузер или [прежний CLI](rebuild.ru.md). Заводские образы и записи уведомлений в исходный архив не включены.
