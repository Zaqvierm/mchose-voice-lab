# MCHOSE Voice Lab v1.1.0

[Website / Сайт / 网站](https://zaqvierm.github.io/mchose-voice-lab/)

## Русский

- 13 оригинальных прошивок для 8 беспроводных моделей; проверенное скачивание оригиналов. V9 Turbo+ 0035 добавлена в браузерный редактор.
- Экспериментальный Python CLI для V9 Pro 2 0032/1002, R9 0018 и G9 V2 0031: чтение и независимый поиск ресурсов, извлечение, кодирование своего аудио, сборка, WAV-предпросмотр и JSON-отчёт.
- Сохранение заводских параметров SBC и проверка JLFS/CRC для G9; отказ от неизвестных оригиналов и перезаписи файлов.
- Исследования, совместимость и инструкции на русском, английском и китайском. Внешние подсказки отмечены отдельно.
- FAQ, Schema.org и понятные ссылки на офлайн-инструменты в интерфейсе.

Браузерная сборка доступна для девяти AAC/ACT-образов. Новые SBC/WTS-профили используют отдельный CLI и не имеют нашей аппаратной проверки загрузки модификации. На сайте для них доступны оригиналы и инструкции. Прямая прошивка устройств не реализована. Версия приложения 1.1.0 не меняет заводские номера версий прошивки.

## English

- 13 official originals across 8 wireless models, verified original downloads, and browser editing for V9 Turbo+ 0035.
- Experimental Python CLI for exact V9 Pro 2 0032/1002, R9 0018 and G9 V2 0031 images: inspect, independently discover, extract, encode user audio, rebuild, WAV preview and JSON report.
- Factory SBC parameters retained; G9 JLFS/CRC verification; unknown originals and output overwrites refused.
- Research, capabilities and instructions in Russian, English and Simplified Chinese, with explicit reference provenance.
- FAQ, Schema.org and offline workflow links in the interface.

Browser rebuilding covers nine AAC/ACT images. New SBC/WTS profiles use the separate CLI and have no project modified-image hardware-boot validation. The browser offers their originals and instructions. Direct device flashing is not implemented. App version 1.1.0 does not change factory firmware version numbers.
