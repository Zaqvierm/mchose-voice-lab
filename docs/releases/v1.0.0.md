## MCHOSE Voice Lab 1.0.0

**[Open the editor / Открыть редактор / 打开编辑器](https://zaqvierm.github.io/mchose-voice-lab/)**

### Русский

Первый версионный релиз браузерного редактора уведомлений MCHOSE.

1.0.0 — версия редактора. Версии образов наушников сохраняются.

- Каталог восьми оригинальных образов для пяти моделей, выбор своей заводской базы.
- Чтение реальных звуковых ресурсов и прослушивание оригинала.
- Обрезка аудио, AAC-LC → ACT, предпросмотр и сборка `.bin`.
- Сохранение программы, DSP, загрузчика, параметров и остальных звуков; проверка контрольных сумм.
- Интерфейс, исследование и инструкция на русском, английском и китайском.

Обработка выполняется локально в браузере. Сайт собирает файл, но не прошивает устройство. Аппаратно подтверждён Power On на X9 с английской 1003; остальные профили проверены программно. Перед установкой ознакомьтесь с [уведомлением о рисках](https://github.com/Zaqvierm/mchose-voice-lab/blob/v1.0.0/DISCLAIMER.md).

### English

First versioned release of the browser-local MCHOSE voice prompt editor.

1.0.0 versions the editor. Headset firmware version identifiers are preserved.

- Eight pinned official images for five models, plus local factory-image selection.
- Actual resource discovery and original-audio preview.
- Audio trimming, AAC-LC → ACT encoding, preview and `.bin` generation.
- Preserved program, DSP, bootloader, parameters and other sounds, with integrity verification.
- Russian, English and Simplified Chinese UI, research and instructions.

User files are processed locally. The application builds images; it does not flash devices. Hardware evidence covers X9 English 1003 Power On only. Other profiles are software-validated. Read the [risk notice](https://github.com/Zaqvierm/mchose-voice-lab/blob/v1.0.0/DISCLAIMER.md) before installation.

### 简体中文

MCHOSE 浏览器本地提示音编辑器的首个版本发布。

1.0.0 是编辑器版本，耳机固件版本标识保持不变。

- 提供五种型号、八个已校验的原厂镜像，也支持选择本地原始固件。
- 读取实际资源并试听原音。
- 裁剪音频、编码 AAC-LC → ACT、试听结果并生成 `.bin`。
- 保留程序、DSP、引导程序、参数和其他声音，验证完整性。
- 提供俄语、英语和简体中文界面、研究记录与操作说明。

用户文件仅在本地处理。网站生成镜像，不直接刷机。硬件验证仅覆盖 X9 英文 1003 的开机提示音，其他配置仅经过软件验证。安装前请阅读[风险声明](https://github.com/Zaqvierm/mchose-voice-lab/blob/v1.0.0/DISCLAIMER.md)。
