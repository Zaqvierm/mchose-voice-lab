# Модели и возможности

[Русский](compatibility.ru.md) · [English](compatibility.en.md) · [简体中文](compatibility.zh.md)

В каталоге 13 оригинальных образов для 8 беспроводных моделей. Браузер редактирует 9 образов AAC/ACT пяти моделей. Отдельный CLI экспериментально собирает 4 образа трёх моделей.

| Наушники | Оригинальные версии | Браузерная сборка | Офлайн-инструменты |
|---|---|---|---|
| MCHOSE G9 Pro | 0026 | Да | Node CLI |
| MCHOSE V9 Pro | 0036 · 1015 | Да | Node CLI |
| MCHOSE X9 | 0038 · 1003 | Да | Node CLI |
| MCHOSE V9 Turbo+ | 0033 · 1002 · 0035 | Да | Node CLI |
| MCHOSE V9 Turbo | 0005 | Да | Node CLI |
| MCHOSE G9 V2 | 0031 | Нет | Python CLI (экспериментально) |
| MCHOSE V9 Pro 2 | 0032 · 1002 | Нет | Python CLI (экспериментально) |
| MCHOSE R9 | 0018 | Нет | Python CLI (экспериментально) |

Обычные V9, S9 и S9 Pro: модели существуют, но проверенные отдельные образы в двух официальных каталогах не найдены. Их прошивки не подменяются образами похожих моделей. Проводные наушники и саундбары исключены.

На устройстве подтверждена только наша замена Power On на X9 EN1003. Декодирование и прослушивание оригинала G9 не считаются проверкой загрузки модификации.
