# MCHOSE V9 Pro 1015 Russian voice prompts

These eighteen MP3 files were generated by the project owner from their own voice reference for the experimental V9 Pro 1015 headset prompt pack. They are shared for community testing and use with compatible custom headset firmware.

The MP3 files are not covered by the repository's MIT license for code. They are not official MCHOSE assets. The reference recording itself is not included. Do not use this pack with the receiver or other MCHOSE models without independent verification.

See [the Russian instructions](../../docs/v9pro-russian-prompts.ru.md), [the English instructions](../../docs/v9pro-russian-prompts.en.md), and [validation scope](../../docs/validation.md).
